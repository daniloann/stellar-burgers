# Stellar Burgers

**Космическая бургерная** — это интерактивное SPA-приложение для конструктора бургеров. Проект выполнен в рамках учебного курса и демонстрирует навыки работы с современным стеком frontend-технологий: React, Redux Toolkit, TypeScript, а также написания интеграционных и unit-тестов.

---

## О проекте

**Идея проекта:** Создать удобный и визуально привлекательный конструктор бургеров, где пользователь может собирать свой идеальный бургер из ингредиентов, оформлять заказ и отслеживать его статус.

**Решаемая проблема:** Проект показывает, как организовать сложное состояние приложения (конструктор, список ингредиентов, данные о пользователе, детали заказа) с помощью глобального хранилища Redux, а также как настроить маршрутизацию для создания многостраничного SPA с защищёнными маршрутами.

**Что я сделал / Моя роль:**
*   Настроил **маршрутизацию** в приложении с использованием React Router, включая создание защищённых маршрутов (например, для страницы профиля).
*   Реализовал **глобальное управление состоянием** на Redux Toolkit: создал слайсы для конструктора, ингредиентов, заказа и данных пользователя.
*   Написал **асинхронные запросы** к API для получения ингредиентов, отправки заказа, регистрации и авторизации пользователя.
*   Покрыл приложение **тестами**: написал unit-тесты для слайсов Redux (Jest) и интеграционные E2E-тесты для проверки ключевых пользовательских сценариев (Playwright).

**Стек технологий:**
*   **Frontend:** React 18, TypeScript
*   **State Management:** Redux Toolkit
*   **Routing:** React Router v6
*   **Styling:** CSS Modules (как видно из структуры)
*   **Testing:** Jest, Playwright
*   **Build Tool:** Webpack
*   **Code Quality:** ESLint, Prettier

## Установка и запуск

Эти инструкции помогут вам развернуть проект локально для разработки или тестирования.

### Требования
- **Node.js** версии 16 или выше
- **npm** или **yarn**

### Шаги по установке

1.  **Клонируйте репозиторий:**
    ```bash
    git clone https://github.com/daniloann/stellar-burgers.git
    cd stellar-burgers
    ```

2.  **Установите зависимости:**
    ```bash
    npm install
    # или
    yarn install
    ```

3.  **Настройте переменные окружения:**
    Создайте в корне проекта файл `.env` и добавьте в него URL API. Пример вы найдете в файле `.env.example`.
    ```
    BURGER_API_URL=https://norma.nomoreparties.space/api
    ```

4.  **Запустите приложение в режиме разработки:**
    ```bash
    npm run start
    # или
    yarn start
    ```
    Откройте [http://localhost:3000](http://localhost:3000), чтобы увидеть результат.

### Запуск тестов

*   **Unit-тесты (Jest):**
    ```bash
    npm run test
    ```
*   **E2E-тесты (Playwright):**
    ```bash
    npx playwright test
    ```

## Как это работает (ключевые сценарии)

1.  **Конструктор бургера:** На главной странице вы выбираете ингредиенты (булки, начинки) из списка. Они добавляются в специальную зону конструктора. Вы можете менять их порядок или удалять.
2.  **Оформление заказа:** После сборки бургера нажмите кнопку "Оформить заказ". Если вы авторизованы, заказ отправится на сервер, и вы увидите его идентификатор и статус в модальном окне.
3.  **Авторизация и профиль:** Вы можете зарегистрироваться или войти в систему. Страница профиля защищена — без авторизации попасть туда нельзя.
4.  **Лента заказов:** (Если реализовано в проекте) Позволяет просматривать историю заказов.
